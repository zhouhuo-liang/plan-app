## 408 四门课：学法决定效率

四门课的性质完全不同，顺序不能乱，学法不能混。

### 总览

| 科目 | 本质 | 难度 | 特点 |
|------|------|:--:|------|
| **数据结构** | 工具箱 | ★★★ | 理解了不需要死背，不理解背了也没用 |
| **计算机组成原理** | 硬骨头 | ★★★★★ | 408 最难。概念抽象、横跨软硬件、知识密度极大 |
| **操作系统** | 中间人 | ★★★★ | 概念多但有逻辑链，抓住主线就不会散 |
| **计算机网络** | 规矩本 | ★★★ | 最好学。背协议+算小题，没有深层抽象 |

> 必须按此顺序学：**DS → 计组 → OS → 计网**。DS 是工具，必须先会。计组和 OS 有交叉点（虚拟内存），放相邻时间学。

### 数据结构：做题比看书重要十倍

最大误区是看懂就过。考试不考"知不知道"，考"能不能写出来"。

代码题三类，优先级从高到低：

| 优先级 | 类型 | 例 | 要求 |
|--------|------|----|------|
| 1 | 线性表操作 | 链表归并、逆置、环检测 | **闭卷默写** |
| 2 | 二叉树遍历 + 递归 | 层次遍历、求深度、判断平衡 | 理解递归展开过程 |
| 3 | 图的遍历 + 最短路径 | DFS/BFS、Dijkstra | 会写并能口述 |

- 代码题必须关掉书白纸写。第一次一定写不出来。第三次还在卡的地方就是真的不会
- 排序算法不要求全部手写代码，但每种算法的过程必须能手动画出来

### 计算机组成原理：408 的鬼门关

计组要求你同时理解三层联动：

```
高级语言（C 代码） → 指令集（汇编） → 硬件（寄存器/ALU/总线）
```

王道的顺序是"数据表示→运算器→存储器→CPU→总线→IO"，但考试最重的题在 CPU 和存储器交叉处。单章看懂了，合在一起做不了大题。

**计组两遍法**：

| 遍数 | 目标 | 方法 |
|------|------|------|
| 第一遍 | 每个概念单独理解 | 跟王道网课一节一节过，做课后选择 |
| 第二遍 | 跨章节串联 | CPU 执行流程大题 = 数据通路 + 指令格式 + 微程序 + 流水线一口气串起来 |

> 第二遍最关键的题：给定一段 C 代码，画它变成指令后 CPU 怎么一步步执行。这是大题常考。

### 操作系统：抓主线

OS 有一条主线，抓住就不会散：

```
进程管理 → 进程怎么创建、调度、通信（PV操作在这里）
         → 进程怎么死（死锁四个条件）
         → 进程的内存怎么管 → 分页/分段/虚拟内存
内存管理 → 虚拟内存 = 进程拿到假地址，OS 映射到真地址
文件管理 → 磁盘上文件怎么找（索引节点、目录结构）
IO管理   → 磁盘调度 + IO 控制方式
```

- PV 操作题是固定题型，刷完王道所有 PV 题，基本覆盖。做题比看书重要
- 不要看文字解释，直接做题——做完再看解析

### 计算机网络：不要当主菜

最简单但也最容易"看起来简单、考试丢分"。小知识点非常碎。

- 1.5 倍速过完王道网课，立刻刷选择。不要在一章上耗太久——上下层会互相帮助理解
- 选择正确率 >85% 后回头查漏补缺
- 出题高度集中在三块：**TCP 拥塞控制、IP 子网划分、应用层协议（HTTP/DNS）**。这三块做到能给他人讲明白

### 四门课时间对齐

| 学期 | 主攻 | 辅助 | 说明 |
|------|------|------|------|
| 大二上 | **数据结构** | 配合学校课程 | 代码题动手写 |
| 大二下 | **计组 + OS** | 配合学校课 + 王道网课 | 计组两遍法，OS 抓主线 |
| 大二暑假 | 计组二刷 + OS 收尾 | 高数启动 | 暑假把最难的啃透 |
| 大三上 | **计网** | 配合学校课 + DS 手感 | 计网 1.5 倍速过，立刻刷题 |

### 验证方法：白纸思维导图

学完一章后，不看书，白纸画这章的思维导图。第一次一定残缺。残缺处 = 没学会的地方。回去补，然后合上书再画一遍，直到完整。**对计组和 OS 尤其有用。**

## 数学一学法：120 分是刷出来的

数学一虽然大二暑假才启动，但学法提前知道可以少走弯路。

### 三分部的性质完全不同

| 部分 | 占比 | 难点 | 错的人都在哪里错的 |
|------|:--:|------|---------------------|
| **高数** | ~60% | 多元微积分、级数 | 计算能力不足。知道怎么做但算不出来 |
| **线性代数** | ~20% | 概念抽象、逻辑链长 | 靠背题型，题目换个形式就不认识 |
| **概率论** | ~20% | 公式多、分布多 | 概念混淆，不知道什么时候用哪个分布 |

### 高数：计算量是练出来的

最大坑：看网课看懂了就过。张宇讲得很爽，但看懂 ≠ 算得出。

- **做题量 > 听课量**。听完一章当天立刻做题。
- 推荐李林 880（难度适中、计算量大、跟真题接近），做完比刷多本更有用。

### 线性代数：不是背套路，是理解线性变换

大部分学生背题型——特征值怎么求、二次型怎么标准化。题目换个问法就不会。

大二上（破冰期）看完 3Blue1Brown《线性代数的本质》——这个视频的价值比所有考研网课都大，因为它让你真正理解"矩阵是线性变换"。有了这个概念基础，再回去看张宇线代 9 讲，以前觉得莫名其妙的东西会变成"原来如此"。

### 概率论：最靠记忆的一门

公式多、分布多，该背就背。但按"公式用在哪里"分类背，不容易混：

```
参数估计类：矩估计、最大似然估计
假设检验类：置信区间、显著性检验
随机变量类：分布函数、期望方差、协方差
```

### 时间线和资料

| 阶段 | 时间 | 任务 | 资料 |
|------|------|------|------|
| 基础 | 大二暑假后 6 周 | 听完高数基础班 | 张宇/汤家凤基础班 + 《复习全书》 |
| 强化 | 大三寒假 | 听完三门强化班 | 张宇《18 讲》+《线代 9 讲》+《概率 9 讲》 |
| 刷题 | 大三下 | 刷完一本习题集 | **李林 880**（推荐）或张宇 1000 题 |
| 真题 | 大三暑假 | 近 20 年套卷，两天一套 | 真题 + 复盘 |
| 模拟 | 大四上 9-11 月 | 模拟卷 + 回归基础 | 张宇 8 套 / 李林 6 套 |

> 数学一最关键的不是听什么课——是**做了多少题**。120 分是刷出来的。

每天抽 30 分钟先把第 6、7 章过掉（大部分是复习），9 月 6 日直接进入第 9 章。


### 每日英语：方法论

每天 50 词不是多了就有用——方法错了背三轮也记不住。

#### 目标基线

英语一目标 75+，词汇量需稳在 5500-6000。你目前大概 3000-4000，差距约 2000 个考研核心词。

#### App 选择

| | 墨墨背单词 | 不背单词 |
|------|-----------|---------|
| 原理 | 艾宾浩斯间隔重复，算法自动安排复习 | 语境记忆，每个词配影视/新闻原声例句 |

| 建议 | **做主背**（每天 50 新词 + 自动复习） | **做辅助**（碎片时间刷例句） |

#### 每日三段式（总计 40 分钟碎片时间）

```

```

#### 什么叫真正记住了

三层标准：

| 层次 | 标准 | 例子 | 何时追求 |
|------|------|------|----------|
| 知道 | 看到 `address` 知道是"地址" | 但考研考的是"解决/处理" | — |
| 理解 | 认识 `address a problem` 是"解决问题" | 真题里出现能反应过来 | **大二上起** |
| 掌握 | 能在作文里用出来 | 终极目标 | 大三开始 |

**核心检验**：墨墨 7 天后推送一个词，你能不能不看提示直接说出来？不能，就是在刷不是在背。在那词上多停 10 秒——读例句、在脑中造一个句子、想象画面。

```
项目名称（中英文）

  ├── 截图/GIF       ← 最重要！先让面试官看到画面

  ├── 技术栈         ← 一行：C++17, Vulkan, GLM, CMake
  ├── 构建方式       ← git clone → cmake → build，三行命令
  ├── 架构简述       ← 可选但加分（渲染管线流程图）
  └── 性能数据       ← 最加分！"720p 跑 120fps，GPU 耗时 6ms"
```

**致命错误**：README 前 30 行全是文字，没有图。面试官不会往下翻。

**最佳实践**：用对比图——"没开 Shadow Mapping"和"开了 Shadow Mapping"并排。效果即时可见。

#### commit 规范

| 不要 | 要 |
|------|-----|
| `fix bug` | `fix: SSAO kernel rotation missing in view space` |
| `update` | `feat: add cascaded shadow maps with 3 splits` |
| 一次提交塞 20 个文件 | 每个功能独立 commit |

面试官看 git log 就能看懂项目的成长轨迹。好的 git log 本身就是简历。

#### 技术文章：写你刚学会的东西

不需要教别人。写你**刚刚学会**的东西——因为你的困惑还新鲜，你知道哪里最卡人。专家已经忘了这些，写的东西新手看不懂。你写的，跟你同级的人刚好能懂。

| 阶段 | 可选题目 |
|------|---------|
| 写完 Shadow Map | "Shadow Mapping 的 acne 问题：我踩的 3 个坑" |
| 写完 PBR | "我花了三天才搞懂 Cook-Torrance 的 D/F/G 三项分别做了什么" |
| 写完延迟渲染 | "G-Buffer 到底存什么？我的一张图解释清楚" |
| 写完整个渲染器 | "从零实现 OpenGL 渲染器的 10 周实战记录" |

300-500 字 + 一张自己画的图 + 一段代码片段 = 一篇。一个月一篇。发在知乎专栏或个人博客（GitHub Pages）。

#### 复利效应

大三联系导师时，你的邮件附上你的 GitHub：
- 三个仓库，README 有对比截图、有性能数据
- git log 干净，每个功能独立 commit

对比另一个学生的简历"我学过图形学，成绩 88 分"——这两者信息量不是一个量级。

> **GitHub 仓库是最硬的简历。技术博客是持续学习的证据。** 不需要等面试才开始展示能力——它们在你睡着的时候也在替你说话。

## 复试双向选择：你必须知道的风险与策略

### 华工录取的真正流程

```
初试成绩 
   → 进复试线 
   → 复试（机试50分+英语10分+综合面试40分）
   → 复试成绩合格 + 排名在招生计划内
   → 进入"双向选择名单"        ← 这只是入场券，不是录取
   → 1-2天内自己找导师签字
   → 导师同意接收 → 拟录取
```

学院官方通知原话：

> "在规定时间内经双向选择无法找到接收导师的学生，原则上不予录取。"

**意思是：复试过了、排名够了，但没导师要你，照样走人。**

### 双选时间窗口极短

2025 年 3 月 23 日公布复试成绩，3 月 24 日下午开师生见面会，**当天就要完成双选签字**。只有 1 天。

### 你不可能到见面会才开始想找谁——那时候已经输了

### 完整攻略时间线

| 时间点 | 动作 |
|--------|------|
| **大三上学期** | 确定 3-4 个目标导师，读他们的论文，了解每个人的方向 |
| **初试结束后** | 估分。若 >370，准备联系材料（简历+GitHub整理+项目截图） |
| **出分当天** | **立刻发邮件给 3 个导师**，标题"2029级统考自荐 - 姓名 - 初试X分 - 图形学方向"，附简历+GitHub+渲染器截图。每个导师的邮件要提到你读过他哪篇论文 |
| **出分后 1 周内** | 若不回复，再发一次。若回复"名额已满"，立刻转向备选 |
| **复试前** | 锁定至少一个对你有正面回复的导师 |
| **复试面试** | PPT 展示渲染器项目，提到目标导师的研究方向 |
| **双选当天** | 直接找已联系好的导师签字，30 分钟搞定 |

### 面试时发现图形学方向满了怎么办

| 情况 | 应对 |
|------|------|
| 图形学导师 A 名额满了 | 立刻问 A 能否推荐同方向其他还有名额的导师 |
| 图形学全部满了 | 转向第二梯队：视听觉与服务计算（许勇）、智能技术与机器人（杜广龙）。你的渲染能力对视觉/AR/VR 方向同样有吸引力 |
| 第二梯队也没坑了 | 接受学院统筹分配。复试排名越高，分配选择越多 |
| 被分配到不喜欢的导师 | 先录取。入学后一个月内通常可申请换导师（存在但不公开说） |

### 最关键的认知

你在双选那一天能不能签上字，取决于你**前两年做了什么项目、出分当天发了什么邮件**。不取决于那天你有多诚恳。

## 图形学数学基础速查

图形学涉及的数学知识，按优先级排列：

| 优先级 | 知识 | 用途 |
|--------|------|------|
| ★★★ | 线性代数（向量、矩阵、变换、特征值） | 变换管线、坐标空间 |
| ★★★ | 微积分（偏导、梯度、数值积分） | 光照积分、PBR |
| ★★ | 四元数（旋转表示、slerp） | 相机、动画 |
| ★★ | 概率论（蒙特卡洛、重要性采样、PDF） | 路径追踪、GI |
| ★★ | 球谐函数（概念层面即可） | IBL、GI probe |
| ★ | 数值方法（牛顿迭代、最小二乘） | 几何处理、拟合 |
| ★ | 傅里叶变换（频谱分析概念） | 抗锯齿、采样理论 |

> 数学不要贪多。线性代数 + 微积分是底线，其他在用到时现学即可。

## AI 时代的图形学：你的定位

### AI 正在改变的

| 已被改变 | 具体技术 |
|----------|----------|
| 超分/补帧 | DLSS、FSR、XeSS — 每个引擎都要集成的标配 |
| 降噪 | 路径追踪降噪已全部换成神经网络（OptiX、OIDN） |
| 3D 重建 | NeRF、3D Gaussian Splatting — 论文井喷，新兴子领域 |
| 纹理/资产生成 | SD、Meshy、Luma — 美术流水线在变 |
| 代码辅助 | Copilot 辅助写 Shader — 降低入门门槛 |

### AI 没改变也改变不了的

- 渲染管线的架构设计 — AI 不知道你的游戏目标硬件
- GPU 性能分析 — 瓶颈定位和针对性优化需要人的判断
- 跨 API 抽象 — Vulkan/DX12/Metal 的工程权衡不是代码生成能替代的
- 实时约束下的取舍 — 16.67ms 预算下哪些效果做、哪些砍
- 论文算法的工程落地 — 算法原型和产品代码之间有巨大鸿沟

### 你的策略

```
传统渲染功底（不变）     +      AI/神经渲染认知（叠加）
      │                                    │
  80% 精力投入                       20% 精力投入
  C++、Vulkan、管线、优化           DLSS原理、神经降噪、NeRF概念
      │                                    │
      └──────────── 交集：CUDA/GPU架构/数学 ─┘
```

- **不追 AI 赛道**：AI/大模型比图形学卷十倍，你在那没有优势
- **不无视 AI**：5 年后面试官大概率会问"你怎么看神经渲染"
- **正确姿势**：渲染功底是底座，AI 认知是第二技能。会用 CUDA 做特征、同时又理解实时约束的人非常稀缺
- **复试差异化定位**：传统图形学项目 + AI 结合的认知，比纯 AI 或纯图形学的候选人更有记忆点

> ## ▌就业优先级总结
>
> ```
> 最稳：客户端开发 ── 岗位多、入行快、渲染器是核武器
> 最赚：GPU/CUDA ──── AI推理+科学计算，天花板在涨
> 最酷：自动驾驶仿真 ─ 蓝海交叉、广州产业带、几乎所有积累都能用
> ```
>
> 这十个方向有一个共同特征：**你不需要重新学一套底层能力。** 只需在已有基础上加一层领域知识。
